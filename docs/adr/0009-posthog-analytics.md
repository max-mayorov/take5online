# Cookieless PostHog for analytics and debugging, proxied through the Worker

Some problems only show up on other people's phones, and the Worker's logs can't show what the browser saw. PostHog (EU cloud, free tier) gives us exception tracking, pageviews and custom events from the app in one place. It runs in cookieless mode: it stores nothing in the browser and counts visitors with a daily-salted hash on PostHog's servers, so, like the rest of the site (whose only browser storage is the strictly necessary seat token and mute choice), it needs no consent banner. Visitors stay anonymous (there are no accounts, see [ADR-0003](./0003-no-accounts.md)); events carry the Room Code and the random Member id, never the Nickname, so a report like "it froze in Room ABCD" can be found; autocapture masks element text and attributes because buttons show Nicknames. Analytics rest on legitimate interest, so a privacy notice at `/privacy` explains them and offers an opt-out, and Global Privacy Control or Do Not Track also turns them off. The SDK talks to `/relay/*` on our own domain and the Worker forwards it to PostHog, because ad blockers commonly block PostHog's hosts. The SDK loads after the app, since it is about as big as the rest of the bundle. The costs: no session replay (it needs browser storage), no location data, the same person counts as new each day, a third party sees how people play, and errors thrown before the SDK loads aren't captured.
